> Directory. Some features described below are planned and not yet implemented — see
> [Features](#features) for exactly which is which.

**PlayerLand** (`mod_playerland`) is a Moodle activity module that embeds a playable **2D
platformer game** directly inside a course. Students control **Huddy** the fox — running,
jumping, dashing, climbing and exploring a level — and answer questions by hitting **question
blocks**, in the spirit of the platformers they grew up with. The game runs on the **Phaser**
engine inside the activity page; levels are authored as Tiled maps, and every bit of educational
logic (questions, mini-lessons, progress, grading) is handled server-side by Moodle web services.
