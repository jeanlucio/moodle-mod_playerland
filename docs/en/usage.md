# 📖 Usage

## For Teachers

1. Add a **PlayerLand** activity to a course and pick a **map** from the dropdown.
2. Set **Questions required to unlock the exit** — the exit flag only completes the level once
   the student has answered this many *distinct* questions correctly. The activity grade scales
   proportionally to this same target.
3. Optionally fill in up to three **mini-lessons** (plain text, 400 characters max each) — each
   non-empty one is shown in-game by its own lesson block.
4. Open **Manage questions** (linked from the top of the activity) to add multiple-choice
   questions. Optionally link a question to one of the three mini-lessons so it appears
   preferentially at the question block that follows it — see [Blocks & Mini-Lessons](#questions).
5. Set the **Maximum Grade** — the proportional grade always scales to it, never to a fixed
   `100`.

## For Students

1. Open the activity and read the first-load "How to play" overlay (shown once).
2. Explore the level: run, jump, collect cherries and gems.
3. Hit a blue "!" block to read a mini-lesson — it can be re-read any time.
4. Hit a yellow "?" block to answer a question; a correct answer counts toward the exit quota.
5. Once enough questions are answered correctly, the exit unlocks — reach it to finish the level.
