# 📦 Requirements

| Component | Version |
|-----------|---------|
| Moodle    | 4.5 – 5.2 |
| PHP       | 8.2+    |

No other plugin is required. Building a fully custom map from scratch (rather than picking one
of the shipped levels) can optionally be done in the free
[Tiled Map Editor](https://www.mapeditor.org/) — see [Gameplay & Movement](#gameplay).
