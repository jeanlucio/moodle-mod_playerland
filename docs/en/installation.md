# 🛠️ Installation & Configuration

> ⚠️ This plugin is not yet published on the Moodle Plugin Directory. Install manually from this
> repository.

1. Download the `.zip` file or clone this repository.
2. Extract the folder into your Moodle `mod/` directory.
3. Rename the folder to `playerland` (if necessary).
   Final path: `your-moodle/mod/playerland/`
4. Visit **Site administration → Notifications** to complete installation.
5. Add a **PlayerLand** activity to any course, pick a **map**, set how many questions are
   required to unlock the exit, and set the **Maximum Grade**.
