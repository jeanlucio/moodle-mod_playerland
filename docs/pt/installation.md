# 🛠️ Instalação e Configuração

> ⚠️ Este plugin ainda não está publicado no Diretório de Plugins do Moodle. Instale manualmente
> a partir deste repositório.

1. Baixe o arquivo `.zip` ou clone este repositório.
2. Extraia a pasta no diretório `mod/` do seu Moodle.
3. Renomeie para `playerland` (se necessário).
   Caminho final: `seu-moodle/mod/playerland/`
4. Acesse **Administração do site → Notificações** para concluir a instalação.
5. Adicione uma atividade **PlayerLand** a qualquer curso, escolha um **mapa**, defina quantas
   perguntas são necessárias para destravar a saída, e defina a **Nota Máxima**.
