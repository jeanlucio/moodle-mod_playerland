# 📖 Como Usar

## Para Professores

1. Adicione uma atividade **PlayerLand** a um curso e escolha um **mapa** no dropdown.
2. Defina **Perguntas necessárias para destravar a saída** — a bandeira de saída só conclui a
   fase depois de o estudante ter respondido corretamente essa quantidade de perguntas
   *distintas*. A nota da atividade escala proporcionalmente a essa mesma meta.
3. Opcionalmente preencha até três **mini-lições** (texto puro, máximo de 400 caracteres cada) —
   cada uma não vazia é mostrada no jogo pelo seu próprio bloco de lição.
4. Abra **Gerenciar perguntas** (link no topo da atividade) para adicionar perguntas de múltipla
   escolha. Opcionalmente vincule uma pergunta a uma das três mini-lições para que ela apareça
   preferencialmente no bloco de pergunta logo depois dela — veja
   [Blocos e Mini-Lições](#questions).
5. Defina a **Nota Máxima** — a nota proporcional sempre escala a partir dela, nunca de um valor
   fixo `100`.

## Para Estudantes

1. Abra a atividade e leia o overlay "Como jogar" do primeiro carregamento (mostrado uma vez).
2. Explore a fase: corra, pule, colete cerejas e gemas.
3. Bata num bloco azul "!" para ler uma mini-lição — pode ser relida a qualquer momento.
4. Bata num bloco amarelo "?" para responder uma pergunta; uma resposta correta conta para a
   cota de saída.
5. Assim que perguntas suficientes forem respondidas corretamente, a saída destrava — chegue
   até ela para concluir a fase.
